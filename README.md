# 📊 CodeAlpha Task 2 — Exploratory Data Analysis

## 📌 Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The objective of this task is to perform Exploratory Data Analysis (EDA) on the Titanic passenger dataset and identify meaningful patterns, trends, relationships, and potential data-quality issues.

## 🎯 Objectives

- Understand the structure of the dataset.
- Explore variables and their data types.
- Identify missing values and duplicate records.
- Perform descriptive statistical analysis.
- Analyze passenger survival patterns.
- Study the relationship between gender, passenger class, and survival.
- Analyze age and fare distributions.
- Detect potential outliers.
- Examine correlations between numerical variables.
- Create visualizations to communicate findings.

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📂 Dataset

The analysis uses the Titanic passenger dataset.

The dataset contains information such as:

- Passenger class
- Gender
- Age
- Fare
- Survival status
- Other passenger-related information

## 🔍 Analysis Performed

The notebook includes:

1. Dataset overview
2. Data types and structure
3. Missing-value analysis
4. Duplicate-value check
5. Statistical summary
6. Overall survival analysis
7. Survival by gender
8. Survival by passenger class
9. Age distribution
10. Fare distribution
11. Correlation analysis
12. Outlier detection

## 📈 Visualizations

The notebook contains visualizations including:

- Passenger Survival Distribution
- Survival by Gender
- Survival by Passenger Class
- Age Distribution
- Fare Distribution by Passenger Class
- Correlation Heatmap

## 💡 Key Findings

The analysis investigates how survival outcomes vary according to passenger characteristics such as gender and passenger class.

It also examines the distribution of age and fare values and identifies potential data-quality issues and outliers.

Detailed results and visualizations are available in the Jupyter Notebook.
